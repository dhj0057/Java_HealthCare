# 하루핏: Java 기반 하루 건강 점수 관리 프로그램

## 1. 프로젝트 개요

**하루핏**은 사용자가 하루 동안의 식단, 운동 시간, 수분 섭취량을 입력하면  
이를 바탕으로 하루 건강 점수를 계산하고 간단한 건강 피드백을 제공하는  
Java 콘솔 기반 건강 관리 프로그램입니다.

본 프로젝트는 Java의 기본 문법과 주요 API를 활용하여  
사용자 입력, 데이터 저장, 조건 판단, 점수 계산, 결과 출력 기능을 구현하는 것을 목표로 합니다.

---

## 2. 개발 배경

최근 개인 건강 관리에 대한 관심이 높아지면서 식단, 운동, 수분 섭취와 같은  
생활 습관 데이터를 기록하고 관리하는 것이 중요해지고 있습니다.

하지만 건강 관리를 처음 시작하는 사용자는 자신의 하루 생활 습관이  
적절한지 판단하기 어렵습니다.

따라서 본 프로그램은 사용자가 직접 입력한 건강 데이터를 기준으로  
하루 건강 상태를 점수화하고 개선 방향을 제시하기 위해 제작되었습니다.

---

## 3. 주요 기능

| 기능 | 설명 |
|---|---|
| 식단 기록 추가 | 음식 이름과 칼로리를 입력하여 식단 기록 저장 |
| 운동 기록 추가 | 운동 이름과 운동 시간을 입력하여 운동 기록 저장 |
| 수분 섭취량 입력 | 하루 동안 마신 물의 양을 L 단위로 입력 |
| 하루 건강 점수 확인 | 칼로리, 운동 시간, 수분 섭취량을 기준으로 건강 점수 계산 |
| 전체 기록 보기 | 입력된 식단, 운동, 수분 섭취량을 한 번에 출력 |
| 프로그램 종료 | 콘솔 프로그램 종료 |

---

## 4. 사용된 Java 주요 기술

| 기술 | 사용 목적 |
|---|---|
| `Scanner` | 사용자로부터 메뉴, 음식명, 칼로리, 운동 시간 등을 입력받기 위해 사용 |
| `ArrayList` | 여러 개의 식단 기록과 운동 기록을 저장하기 위해 사용 |
| `LocalDate` | 현재 날짜를 출력하기 위해 사용 |
| `DecimalFormat` | 수분 섭취량을 보기 좋은 형식으로 출력하기 위해 사용 |
| 클래스와 객체 | Food, Exercise, HealthManager 클래스를 통해 기능을 구조적으로 분리 |
